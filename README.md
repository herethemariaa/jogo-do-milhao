# 🎮 Jogo do Milhão Interativo (Java) - Em desenvolvimento

Projeto desenvolvido em Java inspirado no clássico Show do Milhão, com sistema de perguntas e respostas no terminal.

O objetivo do projeto é praticar:

- lógica de programação
- estruturas condicionais
- métodos
- arrays e matrizes
- interação com usuário via terminal
- organização de código em equipe

# Funcionalidades:

✅ Menu inicial
✅ Escolha de modo de jogo
✅ Perguntas com alternativas
✅ Verificação de respostas
✅ Sistema de premiação
✅ Modo clássico
✅ Modo competitivo

# 🛠️ Tecnologias Utilizadas
☕ Java
📦 Eclipse IDE
💻 Terminal/Console
